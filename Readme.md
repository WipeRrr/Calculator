Hello! Welcome to console calculator.

Enter an expression in the format: number 1 operator number 2 (for example, 2 + 2).To perform an operation on a non-integer number, you must enter it with the \",\" or \".\" symbol.
Supported operators: +, -, *, /,r(root,just write r after digit),%(remainder of division). 
To get the result after the expression, press equals(=)
Press Esc to exit app

If you made a mistake with your input, you can delete it by pressing the backspace button.
